# DASSORU Photography — v4 launch build

GitHub Pages first-launch version for **DASSORU — Photography by Basuru Jayasanka**.

## Launch URL
This build is prepared for:
`https://dassoru.github.io/`

If the GitHub repository is named `dassoru.github.io` under the `dassoru` GitHub account, GitHub Pages can publish this as the root user site.

## Included
- 9 supplied photographs with optimised WebP copies
- Original PNGs in `originals/`
- Portfolio with filters: Wildlife, Nature, Travel, People
- Individual indexable photograph pages
- Personal stories for all 9 photographs
- DASSORU Journal
- Full About page based on Basuru's photography history and philosophy
- WhatsApp and email enquiries for commercial use/licensing
- Facebook, Instagram, YouTube and TikTok links
- Canonical URLs and Open Graph metadata
- Schema.org ImageObject metadata
- XML sitemap with image entries
- robots.txt
- Responsive mobile layout

## Before publishing
1. Create/use the GitHub repository named `dassoru.github.io`.
2. Upload the contents of this `DASSORU` folder to the repository root.
3. Enable GitHub Pages from the repository settings if it is not already enabled.
4. Open `https://dassoru.github.io/` and test the home page, portfolio, Journal, About, social links and WhatsApp link on a phone.
5. Add `https://dassoru.github.io/sitemap.xml` to Google Search Console after the site is publicly reachable.

## Future
A custom domain can be added later without changing the content structure.
